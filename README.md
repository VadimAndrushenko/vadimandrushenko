📱 Адаптивность
- **Mobile-first подход** (от 320px)
- **Адаптивные breakpoints**: 320px, 768px, 1024px, 1440px, 1920px
- **Поддержка устройств**: все современные смартфоны, планшеты, десктопы
- **Тестирование**: Chrome DevTools, реальные устройства, BrowserStack
- **Особенности**: touch-friendly элементы, оптимальные hit-areas, корректный viewport
